# gt5pro-hmbird

真我 GT5 Pro（RMX3888 / SM8650 / ColorOS 16 / 6.1.141 **OKI 基线**）上 **hmbird（风驰）接口层与调度核心**的移植记录。

> 本仓库内容由 **DeepSeek** 协助机主整理撰写。

## 结论（2026-10-09 晚实测）

- ✅ **风驰可在自编内核上跑通**：加载厂商栈后，`scx` 调速器注册成功并可切换，`[scx_gov_init]/[scx_gov_start]` 正常，重负载稳定（详见 [docs/measured-2-20261009.md](docs/measured-2-20261009.md)）
- ✅ **接口层**：`/proc/hmbird_sched` 21 条（装厂商模块后 27 条）
- ✅ **ABI 全程未变**：导出集 **15,489** 逐名一致；493 个厂商模块 missing=0 / crc=0
- ⛔ **不要**用内核开关（`/proc/hmbird_sched/scx_enable`）或搞机工具去**固定** scx 调度 —— **会整机硬挂死**（本项目实测复现过）
- ⛔ 不要用 Scene 的调度 / 第三方调度、游戏线程模块；不要用"官方调度屏蔽"类模块

## 风驰的正确用法（要点）

**内核只负责提供 `scx` 调速器**；开关在厂商/云控侧：

1. 内核：提供 `scx`/hmbird 调速器 + 完整官方调度环境
2. 厂商栈：`oplus_bsp_sched_ext.ko` 等（系统自带，按需加载）
3. **COSA 云控**：提供每款游戏的适配配置
4. **游戏助手**：受支持游戏需在列表中
5. 启动受支持游戏 ⇒ 系统**自动切到 `scx`** ⇒ 退出后自动切回

| 项 | 状态 |

## 适用条件

- 内核基线必须是 **OPPO 系（OKI）**，例如 `6.1.141-android14-11-o-…`；
- 设备树 hmbird 类型为 `HMBIRD_OGKI`（SM8650 即此档）；
- 厂商模块在位，且**按依赖顺序加载**。

## 方法（简述）

1. 以**出厂内核**为基准：符号、CRC、结构体布局逐条比对（BTF 逐字段对偏移）；
2. 以设备上的 **493 个厂商模块**为硬判据：全量审计"能否装载"；
3. 每步过三道闸门 + 真机验收，过不了就回退。

详见 [docs/方法.md](docs/方法.md)、[docs/measured-20261009.md](docs/measured-20260910.md)。
