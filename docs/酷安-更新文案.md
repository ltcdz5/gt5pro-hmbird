【更新】真我 GT5 Pro 自编内核：风驰跑通了 + 一个 3 文件的配套小模块

■ 变化（只讲风驰）

1. 风驰能用了 ✓
游戏运行时，CPU 频率调节器自动切到 scx；退出游戏回到系统默认 uag。
想确认很简单，进游戏后看一眼调速器：
cat /sys/devices/system/cpu/cpufreq/policy*/scaling_governor
出现 scx 就是生效了（用 Scene 也能直接看到当前调速器）。

2. 新增配套小模块 fengchi-boot（3 个文件，约 2 KB）
作者：酷安@天玑1100逆天功耗（github@ltcdz5）
⚠️ 必须搭配我的自编内核使用，单独刷没有任何效果
· 开机把厂商的 scx/hmbird 相关模块按顺序加载好（风驰要用的 scx 调速器就在这一步注册）
· 玩的时候：检测到游戏就切 scx，退出就切回系统默认
· 顺手把 MGLRU 和 horae 也一起做了（原来要装两个小模块，现在一个就够）

3. 两个坑，建议先看一眼
· 建议卸载「官方调度屏蔽」类模块（比如 IMS_VAROS）：它会清空官方调度相关属性，风驰就没法工作
· 可能与 Scene 的调度设置冲突（我没做完整对比测试），建议先关掉 Scene 的调度/调速器设置再试

4. 一条铁律
不要用任何工具去「固定」风驰调度 —— 我实测过，会让手机直接死机。

■ 能不能用

理论上可用，请自行测试。
供参考：我这边第五人格、绝区零进游戏后 policy0/policy7 = scx，重负载稳定，Oops/BUG/panic = 0。
另外：内核导出符号逐名未变（15489 个），493 个厂商模块不受影响。

支持的游戏以厂商云控适配为准（原神、星铁、绝区零、鸣潮、王者荣耀、和平精英、第五人格等数十款），
并且游戏需要先在「游戏助手」列表里。
