# 来源与致谢

本项目的方法与结论参考了下列公开工作。**其中无明确许可证的来源，仅作引用与致谢，不包含其代码。**

## 基准

- **出厂内核本体与其 BTF**：作为逐字段、逐指令的基准（仅用于比对，不随仓库分发）。

## 官方公开源码

- OPPO：`oppo-source`（含 `android_kernel_common_oppo_sm8650`）
- realme：`realme-kernel-opensource`（含 GT5 Pro / GT5 / GT6 各代 drop）
- OnePlus：`OnePlusOSS`（`android_kernel_common_oneplus_sm8650`）

> 注：内核本体为 **GPL-2.0**；其公开 drop 中**不含** hmbird 实现（已核实）。
