## 4. 观测口速查

| 观测口 | 读什么 | 注意 |
|---|---|---|
| `/proc/hmbird_sched/scx_enable` | **意图值** | 不是真状态；被拒时仍读回 1 |
| `/proc/hmbird_sched/hmbirdcore_debug` | 普通 int 节点 | 可作真状态来源之一（@hmbird_sched_proc_main.c:420-423） |
| `dmesg \| grep hmbird_ctrl` | `scx_enable=N -> hmbird_ctrl() rc=…, enabled=…` | 内核在 `ext_ctrl()` **返回之后**才打印（@hmbird_sched_proc_main.c:299）⇒ 看到这行就说明调用已返回 |
| `dmesg \| grep 'hmbird .*finished'` | `hmbird disabled finished at jiffies = …` / `enabled finished` | 只有真收尾才打（@hmbird.c:4570-4580 的 `finish=1`） |
| `/proc/hmbird_sched/hmbird_stats` | 真统计（total_dsp_cnt 等） | 需要 `slim_stats=1` 门控 |
| `/sys/module/kernel/parameters/hmbird_gov_veto` | N/Y（默认 N） | `param_get_bool` 输出 N/Y，不是 0/1（kernel/params.c:317-321） |
| `/sys/module/kernel/parameters/hmbird_partial_util` | N/Y（默认 N） | 同上 |
| `/proc/last_boot_reason` | 上次重启原因 | 判断是否 kernel crash |
